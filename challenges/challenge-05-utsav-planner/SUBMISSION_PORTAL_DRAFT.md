### Field 3: Project Summary / Abstract
```text
Planning large celebrations—multicultural weddings, tech summits, or community festivals—is traditionally overwhelmed by disorganized spreadsheets, budget calculation drift, and vague AI advice. 

UtsavPlan OS is a production-grade, intent-driven event planning assistant built with Google Antigravity and the Gemini 2.5 API. Given high-level user intent, it dynamically orchestrates:
1. Mathematically Balanced Rupee Budgets: Every category (Venue, Catering, Decor, AV, Contingency) is itemized and sums to exactly 100% of limits with zero calculation drift.
2. Backward-Scheduled Gantt Milestones: Generates preparation deadlines counting backward from Event Day (T-90, T-60, T-30, T-7, T-1).
3. Vendor Negotiation Checklists: Lead-time trackers with specific contract negotiation scripts.
4. Personalized Cultural Nuances: Regional tradition adaptations with zero hallucinations.
5. In-App Prompt Inspector: Real-time telemetry auditing system prompts, token flows, and model latencies.
```

### Field 4: Technical Stack

```text
- AI Platform: Google Antigravity
- AI Engine: Google Gemini 2.5 Flash / Gemini 1.5 Pro via Google AI Studio
- Frontend: React 19, Tailwind CSS v4, Lucide Icons, Vite 8
- Testing Suite: Vitest (Unit tests covering budget mathematical consistency, backward timelines, and edge case safety guardrails)
- Architecture: Zero-Crash Mock Fallback Engine + Real-time In-Memory Prompt Logger
```

---

### Field 5: Unique Selling Proposition (USP) & Innovation
```text
Unlike standard chat interfaces that return freeform text or crash when API rate limits hit, UtsavPlan OS features:
1. Zero-Crash Fallback Engine: If an API quota is exhausted during evaluation, the app automatically transitions to high-fidelity mock blueprints without crashing.
2. Embedded Judges DevTools (Prompt Inspector): Evaluators can audit system instructions, temperature, and latency live in the UI.
3. Edge-Case Guardrail: Automatically switches to "Ultra-Thrift Community Potluck Mode" when extreme low budgets are detected.
```
