## ⚡ 3 Most Common Commands You Will Use

1. **Run Your App Locally:**
   ```bash
   npm run dev
   ```
   Opens the live app at `http://localhost:3000`.

2. **Run Pre-Submission Evaluator Audit:**
   ```bash
   npm run validate
   ```
   Automatically verifies 8 evaluator checkpoints before you submit.

3. **Compile Production Build:**
   ```bash
   npm run build
   ```
   Compiles clean production assets ready for Vercel, Netlify, or Google Cloud Run.
